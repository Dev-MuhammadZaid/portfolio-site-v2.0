# Portfolio Assets — Paste Guide

## Favicon
`assets/favicon.svg` is the new MZ SVG favicon. It is already linked in all HTML pages.

## Project mockups
Use `assets/images/projects/project-1-mockup.jpg` through `project-4-mockup.jpg`. They are already connected to the project cards.

## Skill icons
Use the six SVGs in `assets/icons/`: html.svg, css.svg, js.svg, responsive.svg, git.svg, github.svg.

## Development photos
Use `assets/images/development/development-1.jpg` through `development-5.jpg`. They are already placed as large responsive visuals across five pages.


## Existing project
If you are adding these to another copy, copy the `assets/` and `components/` folders, then add the popup CSS/JS and submit logic from `contact.js`.
